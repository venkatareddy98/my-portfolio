# Portfolio – Venkata Reddy Tiyyagura

Static portfolio pages + Express (Node.js) backend for the contact form.

## Run locally
```bash
npm install
cp .env.example .env     # then fill in EMAIL_PASS
npm run dev
```
Open http://localhost:3000. Put your photo at `public/images/venkatareddy.jpeg`.

## Gmail App Password
Google Account → Security → enable 2-Step Verification → App passwords → create one → paste into `EMAIL_PASS`.
